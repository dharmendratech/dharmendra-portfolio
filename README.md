# Dharmendra — Frontend Developer Portfolio

A lightweight, responsive developer portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive modern design
- Mobile navigation
- SEO-friendly metadata
- Accessible navigation
- Lazy-loaded project images
- Projects, skills, experience and services
- Contact CTA
- Download resume link
- No framework or npm dependency
- GitHub Pages ready

## Structure
```text
portfolio/
├── index.html
├── css/style.css
├── js/script.js
├── assets/projects/
├── .gitignore
├── README.md
└── LICENSE
```

## Customize
Replace:
- `your@email.com`
- GitHub and LinkedIn URLs
- Company names and dates
- Project demo/GitHub links
- `assets/Dharmendra-Resume.pdf`

## GitHub Pages
Push the repository to GitHub, then enable:
Settings → Pages → Deploy from branch → main → /root
